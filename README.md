# 🌐 strawhat2511.github.io/formacion-tecnologica/

Este repositorio contiene el sitio web *"Formación Tecnológica"*, un espacio dedicado a compartir conocimientos sobre tecnología, ingeniería, programación, seguridad informática, ciencia de datos, y más, desarrollado como parte de mi formación académica y profesional.

> 🚀 Repositorio del portafolio publicado en:[strawhat2511.github.io/formacion-tecnologica](https://strawhat2511.github.io/formacion-tecnologica/)

## 🌟 Objetivo del sitio

Difundir contenido educativo y proyectos relacionados con la tecnología, especialmente enfocados a estudiantes, docentes y entusiastas del aprendizaje digital. Este espacio se centra en la exploración de conceptos clave, desarrollo de habilidades técnicas y recursos útiles en el mundo TI.
